# 原创漫剧独立入口与小说隔离

> 日期：2026-10-01
> 状态：已实现并完成自动化验证

## 目标

小说入口只负责短篇与连载小说。原创漫剧从侧栏的「原创漫剧」进入，作品、参考方向、卡司、剧集、剧本、分镜和视频提示词都在独立工作区内保存。用户可以参考任意作品或描述一种风格；《屌丝男士》只是一个例子，不是系统内置模板。

## 使用路径

1. 进入「原创漫剧」，填写作品名、原创设定、类型和画风。
2. 在作品工作台先录入参考方向，确认想借鉴的机制，再生成卡司。
3. 为每一集输入情境命题，和 AI 打磨简介；没有想法时可以生成候选梗纲。
4. 确认简介后生成完整剧本。原创漫剧会优先使用带对白、动作和时长的完整剧本，再展开分镜。
5. 修改或确认分镜后生成整集视频提示词，复制到外部视频模型制作成片。

## 隔离边界

- `anime_series.workspace` 区分既有动画短剧与原创漫剧；默认既有数据属于 `anime`。
- 原创漫剧的参考目标写在本系列自己的 `creative_goal` 中，创意接口使用 `original` scope。
- 所有系列、剧集、卡司、剧本、分镜和提示词接口都校验工作区；从另一工作区访问会返回 404。
- 原创漫剧不建立 `Project` 外键，也不写小说项目的 `global_tendency`、DNA、文风档案、章节内容或生成状态。
- 小说接口不再创建新的 `mode=drama` 源书；历史源书仍保留兼容编辑能力。

共享的是动画引擎、校验器和界面组件等实现代码，作品状态和目标数据按记录隔离。这样既避免复制整套生成链，也避免把漫剧要求注入小说提示词。

## 当前边界

当前原创漫剧支持独立的 60/90 秒单集生产、文本参考方向、卡司、完整剧本、分镜和视频提示词。实际视频仍需外部模型完成；本地测试使用模型桩验证链路与隔离，不能替代真实模型内容质量评估。系统可以根据参考提取可执行机制，但不能保证一次抽到商业爆款，也不会复制参考作品的具体人物、台词或剧情。
