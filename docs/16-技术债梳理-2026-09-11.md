## 0. 一句话结论

**这不是一个债务缠身的仓库。** 后端 84.2% 行覆盖、零 TODO 残留、依赖零冗余、有自研架构门禁——底子是好的。

真正的问题集中在三个点，且都属于"**纪律已经建立、但没被机器强制执行**"：

1. **有覆盖率、没门槛** —— CI 跑了 `--cov`，但没 `--cov-fail-under`，Codecov 上传还挂着 `continue-on-error`。84% 只是"观测值"。
2. **有迁移双轨、没收敛** —— `migrate.py` 已长到 1024 行 / 49 个手写函数，与 19 个 Alembic 版本并行。每次加字段都是一次手工同步 9 处的赌博。
3. **有请求层、有 6 个** —— 前端 `api.ts` 1696 行被改了 38 次（200 次提交里），另有 5 个模块各自复刻了一套 `req` + 鉴权头——**代码注释自己写着"api.ts 稳定后可并入"**。

另有一处**对外可信度**的直接伤口：中文 README 已把「可切 Postgres」更正为"不可行"，**英文 README 仍写着 `(Postgres-ready)`**。同一仓库两个相反宣称。

## 2. 债务清单

### P0 — 会真出事

#### P0-1 `api/chapters/extraction.py` 覆盖 14%，而它是核心路径

```
   14%     98    114  app/api/chapters/extraction.py   ← 全仓最低
   17%     78     94  app/engines/drift/self_heal.py
   19%     78     96  app/engines/refresh.py
   20%    111    139  app/api/refresh.py
```

114 条语句里 **98 条没被任何测试执行过**。而这个文件里装的是：`SQLITE_BUSY` 五轮重试循环（`extraction.py:36-134`）、幂等抽取（清旧账）、章节摘要重建、以及 §5.2 那轮踩过的"顺序即契约"编排。

**为什么算 P0**：这是全书一致性的事实入口，改动时没有任何测试网。仓库已有先例——那轮 `_store_end_state` 排在 `lines` 落库之前，全绿套件完全抓不到，只靠断言"适配器调用次数"才暴露。**同类位置、同样的盲区，还开着。**

#### P0-2 迁移双轨未收敛（比上次评估时更重）

| | 规模 |
|---|---|
| `app/migrate.py` | **1,024 行**，49 个 `_add_*` / `_migrate_*` 手写幂等函数 |
| `alembic/versions/` | 19 个版本 |
| `migrate.py` 覆盖率 | 72%（137 行未覆盖） |

加一个字段要同步改 9 处（模型 / Alembic 迁移 / `migrate.py` 补列 + 挂 `run_migrations` / 蓝图 prompt / 解析器 `_FIELD_MAP` / 内容 hash / 级联字段表 / schema 出参 / 前端三处），且迁移必须"先 `upgrade head` 再 autogenerate，再手工精简掉历史变更"。

**为什么算 P0**：这是唯一一处"**照着手册做也可能做错，做错了不报错**"的地方——迁移漏挂 `run_migrations()` 时，开发库正常、生产库缺列。

#### P0-3 英文 README 与中文 README 宣称相反

```
README.md:250      —— 已更正为「改 DATABASE_URL 切 Postgres 目前不可行，需先重写检索层」
README_EN.md:181   —— 仍写 "SQLAlchemy 2.x + SQLite (Postgres-ready)"
```

**为什么算 P0**：中文已诚实化、英文没有。懂行的英文用户第一眼就能拆穿，且这是零成本可修的项。

#### P0-4 覆盖率有观测、无门槛

```yaml
# .github/workflows/ci.yml
python -m pytest --cov=app --cov-report=xml --cov-report=term-missing -q   # ← 无 --cov-fail-under
continue-on-error: true   # ← Codecov 上传失败也不阻断
```

覆盖率从 84% 掉到 50%，CI 依然全绿。

**为什么算 P0**：这直接决定了 P0-1 会不会复发。**没有门槛的指标，半年后一定退化。**
