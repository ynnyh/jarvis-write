# 35 · 去 AI 味 P0 施工方案:文风指纹 + 真人基线标定 + 落库 + 门槛改分位

> 状态:施工方案(**待拍板后开工**;§3 明确划了「不改生产行为」的边界)
> 日期:2026-10-17
> 依据:docs/34(生态对账 + 生产实测)、docs/33(复读判据)、线上 1868 章只读取证(聚合口径)
> 一句话:把「去 AI 味」从**词汇层单一分数 + 整章重写**,换成**文风指纹向量(分维度)+ 真人基线分位标定 + 每章落库 + 分维度门禁**;词汇层规则库降级为其中一个子项,不再当主分。

---

## 1. 病灶(生产实测,已复核)

**1.1 刻度没标定。** 门槛 `DEAI_GATE_SCORE = 6.0`,而线上 1868 章的真实分布是:中位 **1.00**、均值 1.15、最大 6.69。**过线的只有 4 章(0.2%)**。整章级自愈(`deai_self_heal`)在生产里基本空转。注意:生成端的预防(疲劳词表 / 静态黑名单 / 正向锚)每章都在注入、一直在跑;**空转的是事后那一半**。

**1.2 维度不全(真病)。** 对话占比、段长、单句成段占比这些**结构层**指标只在 `FlavorReport.metrics` 里展示,**不进 score、不进门槛**。举证:

| 书 | 对话占比中位 | 段长中位 | 单句段占比 | AI 味分 | 触发了什么 |
|---|---|---|---|---|---|
| 18《裁缝铺里的十年账》 | **10.6%** | 40 字 | 14.5% | 3-5 | 什么都没有 |
| 13《番茄炒蛋与冷面主厨》 | 17.4% | 20 字 | **75.1%** | 2-6.7 | 1 章过线 |
| 19《诡寝惊魂》(导入的真人书) | 44.6% | 30 字 | 71.4% | **0.65** | — |

《裁缝铺》那堵叙述墙(7/7 章对话占比 < 35%)在现有检测器眼里是「干净」的。

**1.3 口径更正(留痕)。** 2026-10-17 上一轮口头结论里说过「分数与人味反向」,**方向读反了**:分数越低越干净,实测 `r(分数, 单句段占比)` 为负,恰恰意味着结构更像人的文本**判得更干净**。而且 1868 章里 1713 章来自同一本真人书,那个相关系数基本等于「人机差异」本身,**不能当定律**。本方案按「**维度不全 + 刻度没标定**」设计,不按「反向」设计。

**1.4 偏离是书级的,不是章级的。** 项目 10《三年》30 章里 27 章偏出、项目 30《超时清算》33/33 章偏出、项目 18 7/7 章偏出 —— 同一本书内跨章高度稳定。所以「按章判这一章脏不脏」必然漏,必须在**书级**定标(这也是 §4.4 门禁要按维度而不是按总分的原因)。

## 2. 人类参照带:来源与口径(必须先说清,否则数字不可信)

**2.1 现有占位带(未标定,只作占位)。** 取证时用的三条带:对话占比 35-45%、段长中位 20-40 字、单句段占比 40-60%。来源是 docs/31 记录的第三方 skill(chinese-novelist)默认文风基准,**是别人的经验值,不是我们实测标定的**。

**2.2 上一轮报的「854/1868 章(46%)掉出人类参照带」就是用 2.1 的占位带算的。** 标定完成后这个数字**必须重算并替换**,本方案把它记为待替换项,不作为结论引用。

**2.3 标定语料(本次新增,可用)。** 项目 19《诡寝惊魂》1713 章 / 313.7 万汉字,用户已确认是**导入的真人文本**(侧证:草稿内容全空、版本快照 0 条、归属生成任务 0 个、状态全 approved,与「整本导入」路径吻合)。

**2.4 版权红线(硬约束)。** 该书正文**不再导出、不入库、不进 prompt、不进任何产物**。标定只产出**聚合分位数**与维度定义,产物里不含任何原文片段或可反推的句子;对外文档只写「真人语料标定」,不点书名。

**2.5 统计口径(必须遵守)。**
- 统计单位是**章**,但同一本书的章高度自相关 → **先在书内聚合,再跨书汇总**,不能把 1713 章当 1713 个独立样本(那等于把权重全给一本书)。
- 每章 ≥ 400 汉字才参与统计(短章噪声大);对话/段落类指标取**中位数**而非均值(分布右偏)。
- 分位取 **p10 / p50 / p90**;「偏出」= 掉出 p10~p90 区间。先不设 p05/p95,宽口径,避免误伤(生态共识:宁可漏改不可误杀)。
- 标定脚本必须打印**参与标定的书数 / 章数 / 每书样本量**;书数 < 3 时只输出「参考带」并显式标注置信度低。

**2.6 一次性跑批留档。** 标定产物版本化为 `style_baseline v1`,并在本文件附录贴一次实际读数(可复算)。

## 3. P0 范围与边界

**做**:指纹维度与算法单点化 / 标定脚本与基线产物 / 每章指纹落库 / 门禁从单一分数改维度分位 / 全书曲线接口。
**不做(本阶段)**:采样参数(`openai_compatible.py` / `gemini.py` 两个禁改文件,用户未答)、主路径「整章改定点 + 编辑预算」(docs/34 §3.2,P1)、机械保真校验器(docs/34 §3.1,P1)、黄金集与误改率门槛(docs/34 §3.5,P2)。
**生产行为边界**:P0 的门禁先以 **advisory(只提示不拦截)** 上线;`blocking` 待黄金集标定后再开。这条不是保守,是生态里工程最彻底的几家(`avoid-ai-writing` 门禁门在 `issues.length` 而不在分数、`shuorenhua`/`oh-story` 明文拒绝单一分数)的共同做法。

## 4. 设计

### 4.1 指纹维度表(单点化在 `app/engines/style/fingerprint.py`)

| 维度 key | 算法 | 为什么单列 | 现状 |
|---|---|---|---|
| `dialogue_ratio` | 引号内汉字数 / 总汉字数(保护区间复用现有 `_protected_spans`) | 对白是网文主要推进手段;掉到 10% 就是「叙述墙」 | **新增** |
| `para_p50` / `para_p90` | 段落汉字数中位 / 90 分位 | 段落呼吸;两本书的偏离方向相反(40 字 vs 20 字)都出在这里 | **新增** |
| `para_one_sent_ratio` | 单句成段段数 / 总段数 | 节奏的另一端:《番茄炒蛋》75-86% = 一段一句 | **新增** |
| `sent_p50` / `sent_sigma` | 句长中位 / 标准差 | burstiness 的稳健版(现有 σ/μ 在短章上不稳) | 部分有 |
| `narration_distance` | 一/三人称代词占比 + 心理动词密度(想/觉得/记得/意识到),**proxy** | 叙述距离是「贴着人物写」的可量化代理 | **新增(标注 proxy)** |
| `simile_per_1k` | 比喻连接词(仿佛/宛如/好似…)密度 | 已有规则 | 已有(进分) |
| `abstract_per_1k` | 抽象意象(涟漪/潮水/目光/空气/深处…)密度 | 已有规则 | 已有(进分) |
| `dash_per_1k` | 破折号 / 省略号密度 | prompt 明写 ≤3.3/千,实测 4-8/千(约束写了不执行) | 已有(未进分) |
| `tail_summary_per_1k` | 段尾总结/点题句密度 | 「段尾不升华」是硬规则 | 已有(未进分) |
| `ttr` / `novelty_4gram` / `de_ratio` / `funcword_density` | 现有第二裁判四项 | 词汇丰富度,防「洗掉人味」 | 已有 |
| `repeat_hits` | 章内长重复 + 跨章句复现 | 自我复述 | 部分有 |
| `vocabulary_hits` | 现有 9 类规则库加权命中 | **降级为子项**,不再当主分 | 已有(原主分) |

每个维度输出:`raw` 值 + 对基线的 `pct`(分位) + `out_of_band`(是否偏出)。

### 4.2 基线产物

- 模块:`app/engines/style/baseline.py`;产物 `app/engines/style/style_baseline.json`(版本化,**入包**,便于随代码回滚)。
- 结构:`{version, built_at, source:{books, chapters, note:"真人语料聚合,不含原文"}, dims:{key:{p10,p50,p90,unit}}, by_genre:{...}(可选)}`
- 标定脚本:`backend/scripts/calibrate_style_baseline.py` —— 只读 DB、只输出聚合;**脚本内显式禁止打印/导出正文**。

### 4.3 落库

- 新表 `chapter_fingerprints`:`id / project_id(idx) / chapter_number / dims(JSON) / out_of_band(JSON) / score_v2(float) / created_at`。**新表走 `Base.metadata.create_all` 自动建**,不需要在 `migrate.py` 补 ALTER(CLAUDE.md 的规矩只针对改已有表的列)。
- 写入点:`chapter_finalize` 定稿之后(与现有 deai 报告同一处),**失败静默**——指纹是观测,绝不能拖垮生成。
- 回填:`scripts/backfill_fingerprints.py`,对存量章逐章写 dims(幂等),同样只写聚合、不导出正文。
- 接口:`GET /api/projects/{pid}/fingerprint-curve` → 逐章 dims + 偏出标记;前端先接在「全书 → 体检」页签。

### 4.4 门禁改分位(核心变更)

- **现在**:`score > 6.0` → `deai_self_heal`(整章)。
- **改为**:逐维度与基线比 → 得到**偏出维度集合**;`blocking` 维度偏出 → 触发**该维度定向**修复(段落级,复用 `deai_heal_repeats` 已经跑通的框架);`advisory` 维度只进报告不动作。
- 单一 score **保留为展示分**,不再当门禁 —— 与 `avoid-ai-writing`「有分但门禁不用分」同构。
- 灰度开关:新增 `AppSetting(ai_flavor_config).gate_mode = "score" | "bands"`,**默认 `score`(即现状)**,灰度验证后再切 `bands`。回退就是改这一个值。
- **安全阀三道不动**:篇幅比 `0.75~1.25`、`judges_regress`、`overcorrected`。

### 4.5 与现有实现的关系(明确不推翻什么)

- **保留**:9 类规则库(降为子项)、第二裁判四项、`deai_self_heal` 的循环与安全阀、`deai_heal_repeats` 的段落级框架、双向锚定与 voice 注入、`ai_flavor_config` 热更通道。
- **新增**:指纹向量、基线产物、落库表、分维度门禁、曲线接口。
- **替换**:门禁的**判据**(单一分数 → 维度分位)、以及**触发语义**(不再等总分超标,维度偏出就动)。

## 5. 施工步骤(每步独立验收)

| 步 | 内容 | 验收 |
|---|---|---|
| S1 | `fingerprint.py` 单点化 + 纯函数单测 | 给定文本出维度值;短章(<400 字)/空章/对白密集三个边界各一例 |
| S2 | 标定脚本 + `style_baseline v1` | 打印书数/章数/每书样本量 + 分位表;读数贴本文件附录,可复算 |
| S3 | `chapter_fingerprints` 表 + 定稿写入 + 回填脚本 | 新章自动落行;回填幂等(跑两次行数不变);写入失败不影响生成 |
| S4 | 曲线接口 + 体检页签 | 接口返回逐章 dims;页签能画出「对话占比 / 段长 / 单句段」三条线 |
| S5 | 门禁 `bands` 模式(advisory 先行) | 开关默认 `score`;切 `bands` 后偏出维度进报告、**不触发**重写 |

**门禁**:backend `python -m pytest -q` 全绿 + 新增用例;frontend `npx tsc --noEmit` + `eslint` + `vitest run` 全绿。

## 6. 风险与回滚

- **误杀**(生态共识里最大的风险):advisory 先行;`blocking` 只在黄金集标定后开。
- **基线偏差**:真人语料目前只有一本 → 先出「参考带 v1」并标注置信度;补语料后升 `v2`,分位表进版本控制,可比对。
- **性能**:指纹是纯正则 + 统计,O(章长),单章 < 10ms;落库一次 INSERT。
- **回滚**:`gate_mode` 切回 `score` 即恢复现状;新表不影响任何既有路径(纯追加)。
