# 功能导览

面向使用者的功能介绍。技术细节见各篇[设计文档](/00-overview)。

## 以章节为中心的写作工作台

界面按「你在写书，不是在走流水线」组织成三个区：

- **开书 setup**：概念 → 架构 → 大纲，保留向导感，一步步把书立起来
- **写作 write**：正文即界面——打开就是本章正文，选中任意段落就地「改这段 / 手改」（①档），读到多处问题边读边批注、一次性定点改（②档）；一条常驻 **AI 窄栏**是你的合著者，梳理修改意见清单后锁情节整章优化（③档）或推倒重写（④档）。AI 改完不覆盖，一律 **diff 逐条验收**；章首一张**交稿单**用一句话报告本章自检（校对、与设定有无冲突），要改的一键带进验收流。目录是可唤出的抽屉（点章题 / `Ctrl+B`），连写收在目录里
- **全书 book**：看板（概览 / 人物 / 圣经 / 伏笔）、投稿导出、全书体检、翻新批量工具

另有书级设置（字数守卫 / 审校把关 / 连写要求 / 世界观硬规则）和只读阅读页。

## 真流式对话与逐章生长

把「等」改成「看它写」：

- **对话真流式打字机**：AI 窄栏里的选段讨论、整章问答、重写研讨，回复逐字往外蹦（像真人敲键盘），首字未到时原地转圈；聊完自动收敛出「修改意见 / 改写建议」与档位建议，一键带进改稿。基于 `fetch` + `ReadableStream` 手工解帧（带鉴权），并显式关掉反代 / CDN 的响应缓冲，经中转站也不被攒着一次性下发。
- **蓝图逐章生长**：生成章节蓝图时，进度实时显示「已生成 N / 共 M 章」，边生成边数章节头，看着章节一条条冒出来；流式不可用时自动回落一次性调用，不影响生成。

## 命令面板与快捷键

手不离键盘：`Ctrl+K` 唤出命令面板——输入 `37` 跳 37 章，输入章名模糊匹配，输入「润色 / 校对 / 评分」直接执行动作。其余快捷键：`Ctrl+Enter` 生成本章、`Ctrl+[` / `Ctrl+]` 上一章 / 下一章、`Ctrl+B` 开合目录抽屉、`F11` 沉浸模式（只留正文）。快捷键在浏览器和桌面客户端里同样生效。

## 长程一致性引擎

写到几十万字不崩的底气：

- **时序故事圣经**：每条事实绑定生效章节区间，可以回答「第 N 章时这个角色是什么状态」
- **伏笔四态调度**：埋设 / 强化 / 回收 / 弃用，到期未回收自动提醒
- **契约与门禁**：章后自动抽取实体与事实写回圣经；章末还留一份「交接契约」——时间 / 地点 / 在场人物即时状态 / **环境氛围（天气·光线·声音）**，下一章开头必须与之吻合，专防「上一章四下寂静、没有一只鸟雀，下一章却被鸟叫吵醒」这类环境凭空翻转；定稿后与圣经比对找矛盾，问题列表交你拍板，不擅自改稿；真被拦下时，章首弹**一张说人话的卡**——一句话讲清和哪条设定撞了，给三个明确选择（让 AI 按这条重写 / 去改设定 / 就这样忽略继续），不必再懂「放行 / 契约重提」这些黑话

详见 [03 · 三大引擎设计](/03-engines) 与 [08 · 章节生产流水线与前后审核体系设计](/08-章节生产流水线与前后审核体系设计)。

## 大纲级联更新

改任意一章大纲，系统自动做改动分级（小改零成本短路）→ 下游影响分析 → 你勾选后级联重生成；已有正文自动标记失配，大纲全程版本化可回退。同类开源项目里独一份。

详见 [03 · 三大引擎设计](/03-engines)。

## 章节标题：先定调，一键换一整批

治「AI 起名个个『惊天逆转！命运终章！』」的标题党老毛病：

- **生成前先定调**：生成章节蓝图前选一档标题风格——**朴素 / 带钩子 / 悬疑冷峻 / 含蓄诗意**，还能补一句自由要求；风格导向贯穿整书蓝图，硬约束常驻（不标题党、4-12 字、像正经出版目录、不用感叹号）。
- **成书后一键批量改名**：已经写好的书，在大纲页一键为全书（或指定章）重拟一整批标题，old→new 逐条预览、勾选、可自改、还能「再换一批」；**只改标题、不动剧情简述，已写正文不会被标失配**。长书自动分批调用，进度实时上报。
- **单章当场改**：写作页每章标题旁就能自己敲一个，或点「让 AI 换个不夸张的」出几个克制贴题的候选，点一下即用。三处改名共用同一套风格预设，措辞统一不漂移。

## 编辑部：评分 / 校对 / 审核

主审按情节 / 文笔 / 节奏 / 人物四维给章节打分，校对抓错字病句，全书体检聚合审核报告。生成时的自动修复清单与手动待修清单留存可查，正文一旦改动自动失效，不留过期误导。审核体系的设计见 [08 · 章节生产流水线与前后审核体系设计](/08-章节生产流水线与前后审核体系设计)。

## 润色锁定情节

- **润色锁定情节**：整章或选段风格化润色，润色前从故事圣经抽事实清单、润色后逐条校验，情节事实不变；附带重复用词检测，提示高频比喻 / 情绪短语引导换表达
- **重写前先聊**：重写前与 AI 多轮对话蒸馏出精准修改意见，再据此重写，避免「AI 猜你想要什么」

详见 [03 · 三大引擎设计](/03-engines) 与 [04 · 标签化倾向系统](/04-tag-system)。

## 去 AI 味（双向锚定 + 自愈闭环）

把「一眼读得出是 AI 写的」当头号敌人来打——这一版的重中之重。从旧版「只检测、只提示」升级为「双向锚定 + 量化门禁 + 自愈闭环」：

- **正向锚·名家 / 预设文风范本**：给笔法一个具体的「人」去学。内置余华、鲁迅、汪曾祺、金庸、王小波、海明威等文风胶囊任选，也可喂自己的范文、或从你已认可的章节自动提取文风
- **负向锚·✗AI 腔→✓人话 配对反例**：把神态套话、升华点题、论文式罗列、比喻堆砌等常见套话，逐条摆成「✗ 这样写 → ✓ 改成这样」的反例让模型照着划掉
- **量化 AI 味门禁**：定稿再过一道检测——9 类套话规则库（含专揪「脑内涟漪 / 仿佛有人在很远的地方呼唤 / 无形的手」式空洞比喻的重罚旁路）+ 4 项句式统计（句长 burstiness / 节拍器句组 / 段落结构 / 长重复）打出 AI 味指数；超标就定向去味重写 → 复测 → 收敛，最多两轮，没改好自动回退、绝不落更差的版本
- **铺满所有入口**：正向锚不止用在草稿，一路铺到续写、片段润色、整章润色每一个生成入口；看板与结果卡都显示 AI 味指数，哪章该返工一目了然

> 版权红线：在世作家（余华等）绝不嵌入原文，所有文风范本均为本项目自撰仿写，界面与接口统一标注「风格参考·非原作节选」。

详见 [03 · 三大引擎设计](/03-engines)。

## 已有书翻新

旧书不是废稿：旧章节按新逻辑重构——回填场景节拍、初始化文风备忘、轻度重润（锁情节）或重度重写（整章重跑）；中途失败已完成章进度保留，可续跑剩余章节。详见 [03 · 三大引擎设计](/03-engines)。

## 看板与投稿导出

质感看板带主审四维评分与 AI 味指数，哪章该返工一目了然；人物 / 圣经 / 伏笔各有独立看板。整本可导出 txt / epub 用于投稿，token 用量统一埋点、实时统计。

## 漫剧工坊：小说一键改编漫剧

「全书 → 漫剧」页签：把已定稿章节改编成竖屏漫剧的**完整拍摄手册**，五步流水线每步独立可重跑，拿去即梦 / 可灵 / Midjourney / 剪映照单施工出片。沿用「只产提示词」哲学——不接生成模型、零新配置，AI 编排与导演知识归我们，出图出声出片归你手里的工具。

工作台本身按剧组分工组织：顶部**管线步骤条**点亮即完成、点按即跳转；桌面端左侧**资产侧栏**常驻（风格卡 / 角色卡 / 场景卡随取随改），右侧主区专注切集与单集流水线；移动端自动回落单列，顺序就是工作流顺序。

### ① 画风方向，你拍板

生成任何东西之前先定方向：**国漫厚涂 / 日系二次元 / 3D 动画 / 水墨国风 / 赛博霓虹 / 真人写实**，或交给 AI。方向是硬约束——风格锁定段、每一格分镜提示词全部锁死在所选方向内，选了水墨就不会蹦出赛博霓虹；想全片换皮，换个方向重新生成风格卡即可。

- **AI 荐方向**：不确定就点一下，AI 按本书的题材 / 基调 / 场景推荐前三个方向，按优先级排序、每条带扣题理由（第一名标 ★），点一下即选中——推荐只是建议，随时可以无视
- **真人写实挂警示**：AI 真人目前仍有恐怖谷痕迹、跨镜头一致性更难，选项保留但明示风险；动画系才是当前 AI 出片质量的真实水位，也是默认推荐

### ② 资产卡：一致性的锚

- **美术风格卡**：一段「画风锁定」（媒介 / 笔触 / 色彩 / 光影），逐字注入每一格分镜——上百格画面画风不漂移
- **角色卡**：从故事圣经批量生成「锁定外貌段」（发型面容 / 服饰材质颜色，必须可画）+ 配音声线；角色出场的那格逐字嵌入他的外貌锚，**同一个人不换脸**；手动调过的卡点「锁定」，批量重跑不覆盖
- **场景卡**：反复出现的场景一张定调卡，同名场景跨集画面基调统一
- **兜底**：LLM 偶发漏注入锚段时，引擎层确定性检查并强制拼入——一致性不靠模型自觉

### ②-1 定妆照：把「锁脸」从文字提升到像素

文字锚只能把跨镜头漂移压小，压不到零——同一段外貌描述交给生图站，两次出图仍是两张脸。真正锁脸要靠**参考图**，所以角色卡上有一步「出定妆照」：

- **AI 写参考图专用提示词**：单人正面半身居中、纯色浅灰背景、柔和均匀光、3:4 画幅，带上本书画风锚与该角色的锁定外貌段——出来的就是一张干净可复用的定妆照，不是剧照
- **出一次，全片复用**：你去生图站出图，满意了**上传回角色卡**（也可只贴外链）。之后凡是这个角色出场的分镜，粘贴版会自动多一句「【参考图】用『某某』的定妆照」提醒你在生图站上传垫图——文字锚 + 参考图双管齐下，是当前业界最稳的一致性做法
- **只补缺，不覆盖**：批量「出定妆照」只给还没有的角色生成（全都有就直接告诉你，不空跑一次 AI）；要重写某一张，点那张卡上的「重出提示词」显式覆盖，手改过的内容同样受「🔒 锁定」保护
- **上传按文件内容判定**：只收真的 PNG / JPG / WebP（改扩展名无效），文件名由服务端生成，单张 4MB、每角色最多 3 张、单项目总量 80MB；图片读取走登录鉴权，跨用户看不到

### ③ 切集：按短剧行规，不机械等分

选已定稿章节范围，AI 按短剧节奏切集（默认约 90 秒 / 集，对白演绎 / 口播解说双模式）：每集**独立小冲突 + 开场 3 秒钩子 + 结尾卡点**，逼观众点下一集；一章可拆多集、数章可并一集，以冲突密度为准。3000 字一章大约出 4-6 集。重新规划只替换所选范围，范围外不动。

### ④ 单集流水线：剧本 → 分镜 → 三轨提示词 → 成片包

- **剧本**：台词口语化、每句可拍，开场承接上一集卡点、结尾落在悬念上
- **分镜表**：每格 2-8 秒（对齐图生视频工具的单段时长），带景别（远全中近特）、运镜（推拉摇跟随）、台词与画面描述——景别有节奏、情绪重音用特写，这些导演决策由 AI 做
- **三轨提示词**：中文六层（主体 / 场景 / 氛围 / 光影 / 构图 / 画风）+ 英文 MJ 版 + 负面词，锚段已注入，逐格可手改
- **一键粘贴，按你用的生图站适配**：提示词有正文、有负面词、还有比例，到了生图站不知道往哪儿粘——每格给三份现成的，选一次记住：① **只有一个描述框**的站（GPT-image / DALL·E / 豆包 / 通义）把负面词改写成「【不要出现】…」并入正文、比例构图一并写进去，**整段粘一次就行**；② **有负面词框**的站（即梦 / 可灵 / SD / ComfyUI）正文与负面词分开两枚按钮；③ **Midjourney / Niji** 用英文 + `--ar 9:16` + `--no` 排除项。三份由后端同一套规则生成，站内所见、导出手册、CSV 完全一致；CSV 另有 `paste_oneframe` 整段列，批量出图按列复制
- **成片包**：**配音稿**（TTS 友好朗读文本、发音人、声线、估时——配音与画面时长不匹配会提示「延长镜头或提语速」）+ **剪辑清单**（镜头顺序 / 时长 / 字幕 / 转场建议 / 按段打标的配乐情绪）+ **SRT 字幕**（按分镜时长确定性生成，剪映 / PR 直接导入）
- **声线选型**：每个角色补 TTS 平台选型建议（剪映朗读 / 火山引擎 / MiniMax 方向）与朗读指示（语速 / 情绪基调 / 重音）

出片顺序一句话：**先出角色定妆照** → 逐格出图（带上定妆照当参考图）→ 图生视频 / 加轻动 → 按配音稿合成语音 → 按剪辑清单拼接 → 压 SRT 字幕 → 铺 BGM。

### ⑤ 预告片：一键高能混剪

从各集的钩子 / 卡点 / 高能分镜里混剪一条 30-60 秒宣传片：炸点开场 → 世界人设速览 → 冲突升级连切 → 悬念定格 + 标题卡。产物含**文案骨架**（旁白 + 金句）、混剪分镜表（每格标注取材自第几集，新创镜头单独标）、三轨提示词（锚段注入规则与正片一致）；可导出拍摄手册与 SRT。预告片不剧透关键反转，只放大悬念。

### 配音合规红线

声音受法律保护（2024 年全国首例 AI 声音侵权案已判）。本工坊的配音方案从设计上就走安全区：

- **只用音色特征描述**（性别 / 年龄段 / 音色气质），指向 TTS 平台**正版音色库**选型，不做声音克隆
- 声线选型内置硬规则：**绝不指名或暗示模仿任何真人 / 演员 / 声优的声音**
- 界面常驻提醒：商用发布前确认所选音色的**商用授权**（部分平台音色分个人 / 商用授权）

## 宣传片工坊：先聊透方向，再动手拍

书房第二个视频工坊，做城市 / 景区 / 品牌宣传片（`/promo` 独立入口）。核心理念是**先聊后做**——宣传片的前期策划本来就是策划总监和客户多轮对出来的：

- **多轮研讨（流式打字机）**：与 AI 策划总监就着主题聊——你说「想从吃的入手」，他反问最关键的一两个问题（受众？要大气还是烟火？）、给具体到画面的建议（「凌晨四点的头汤蒸汽开场，比航拍更适合竖屏」）、每轮复述共识；拿不准的事实他会请你补素材，而不是替你编
- **收敛成创作简报**：聊透了一键蒸馏出结构化契约——一句话定位、受众、基调、核心信息、段落结构（每段角度/时长/内容）、slogan 候选、**⚠需人工核实清单**；简报可编辑、可锁定、可重新收敛，后续解说词与分镜全部按简报执行
- **素材点事实红线**：史实、年代、数据、称号只可引用你给的素材点；简报里拿不准的点自动进核实清单。宣传片把钟楼年代写错就是事故，这条纪律是底线
- **全链路产出**：视觉风格卡（六方向硬约束）+ 地标卡（场景锚）→ 解说词（旁白语速按 4 字/秒贴时长）→ 分镜 → 三轨提示词（画风/地标锚逐字注入）→ **生成切段** → 成片包（配音稿 + 剪辑清单）→ 手册 / CSV / SRT / JSON 导出
- **生成切段（画布拼接工作流）**：按镜头边界贪心并段（≤5/10/15 秒可选，绝不在一个镜头中间切断），每段给整段**视频提示词**（写运动与时间展开，文生视频直接用）、**首帧指引**（图生视频用哪格静帧起手）、拼接提示；时间码与 SRT 字幕同轴——一段一次生成，拖上画布照序拼

## 情绪短片工坊：15/30 秒，一次三本子三选一

书房第三个入口（`/clips`），做情绪命题短视频。设计逻辑是**短视频试号**：同一命题一次产 3 个不同切入的本子，点卡选定，不合适「换一批」，不磨单版。

- **十大情绪命题**：遗憾 / 争吵 / 爱情 / 童趣 / 思念 / 孤独 / 治愈 / 热血 / 告别 / 重逢——每个带「导演提示」（遗憾=克制冷藏、最后一格才许破防），也可自定义命题；可加一句灵感种子（「异地恋的最后一通电话」）
- **每个本子自带完整物料**：一句话 logline、情绪曲线（平静→屏息→空）、投流钩子文案、台词、分镜表（3-7 格）、三轨提示词（画风锚逐字注入 + 引擎兜底）、**金句字幕卡**（≤16 字，拒绝「珍惜眼前人」式正确废话）、切段（15s 通常一段一次生成）、SRT
- **小说衍生入口（壁垒所在）**：小说项目「全书 → 投流」页签——AI 读你最新定稿章节，挑最戳人的金句与名场面出 3 个投流本子（不同卖点切入：最狠反转 / 最戳感情线 / 最强设定）；**金句溯源校验**：每个本子必须给出金句在正文里的原句（quote_source），引擎做逐句比对，编造的引用当场标进「需核实」；出场角色自动复用漫剧角色卡的锁定外貌段——同一个人不换脸。**它读的是你的书，引用的是你写的话**，这是和通用 AI 聊天拉开差距的地方

## 灵感工坊 & 故事工坊：「选玩法让 AI 编」和「我的点子直接拍」

情绪短片之外的两条短视频心智（`/inspire` 与 `/free` 独立入口），与情绪短片共用批产三本子三选一 → 手卡 → 出片盘的同一套管线：

- **灵感工坊（玩法短视频）**：治愈手绘 / 黏土定格 / 赛博雨夜 / 像素复古 / 港风胶片 / 动物拟人 / 荒诞脑洞等十二种玩法，玩法 directive 自带强画风锚，画风气质一眼可辨；允许荒诞与反差，越有梗越对——做账号试号、日常更新的批量产线
- **故事工坊（自由创作）**：你突然冒出一个具体场景时进的那条——一段话把点子写下来（如「小朋友和妈妈坐出租车，车上的搞笑对话」），点子即命题：AI 以**你的点子为本子主轴**，第 1 个本子忠实还原你的故事（人物 / 场景 / 对话与笑点照它原样出），另两条保留同一场景换镜头语言 / 叙事顺序的变体，**禁止另起炉灶编新故事**；带意见「换一批」仍围着你的点子收敛
- **画风任选动画系**：Q版沙雕漫画（二头身 / 粗描边 / 表情包式夸张表情，段子类主力）/ 日系二次元 / 国漫厚涂 / 3D 动画 / 手绘水彩等十余档，三条出片线共用一份目录
- **角色定妆卡**：手卡把出场角色聚合成按人一张的定妆描述（性别 / 体型 / 发型发色 / 五官 / 着装，跨镜一致），一键复制去文生图出定妆照，上传出片盘当参考图——先锁脸再逐段出片，人物不漂

## 生日祝福工坊：30/60 秒，给寿星定制的祝福片

第四条出片线（`/birthday`）。与情绪短片同形（批产三本子三选一 → 手卡 → 出片盘），但输入不是命题，是**结构化寿星资料**——定制片的灵魂在于拍的是这个人：

- **寿星资料**：称呼（祝福台词点名用，如「老王/糖糖/妈」）、关系（妈妈/伴侣/闺蜜/同事…决定视角与口吻）、里程碑（周岁/18 成人礼/60 大寿，快捷 chips+自填）、**回忆点 2-5 条**（每条一个具体场景/梗/口头禅——分镜只从这些点选材）、送出人（自己/全家/闺蜜团，决定「我」还是「我们」）
- **儿童向风格包（内置六套「世界包」）**：佩奇式简笔动画 / 奥特曼式特摄英雄 / 汪汪队式 3D 救援 / 恐龙世界 / 童话城堡公主王子 / 小小宇航员登月——每包自带**强画风锚 + 世界观场景词 + 主角植入指令**：寿星以该世界的角色形象作为主角贯穿每一格（变身小小英雄与巨人并肩对战怪兽、当救援队长指挥狗狗队完成小任务…）。版权口径与灵感工坊 ghibli 先例一致：UI 标签提示「同款气质」，提示词只描述画风特征与世界观、不点名品牌/IP。选包后通用画风不再注入（两套硬约束会打架）；出片时传小朋友照片当参考图走图生视频，TA 就出现在那个世界里
- **六大基调，各带三幕节奏契约**：整蛊爆笑（伪装正经→最后一帧全员亮蛋糕）/ 催泪走心（回忆物件特写，收在迟到的那句话）/ 温馨日常 / 惊喜反转（假装忘了→暗地策划→引爆）/ 燃向里程碑（把年龄拍成勋章）/ 宠溺可爱；结构铁律进提示词正文：开场 3 秒点名抛悬念、禁蛋糕空镜开场，高潮收在吹蜡烛/拥抱那一帧
- **回忆点防编造校验**（生日版的金句溯源）：候选全部分镜/台词与每条回忆点做关键词核对，对不上的标进「需核实」——定制片最怕张冠李戴的「假回忆」，宁可误报让用户看一眼
- **分段出片玩法指引**（借鉴开源视频 skill 的能力分类）：普通段复制提示词走文生视频；**回忆杀段传寿星真实照片走图生视频**（提示词已含「保持参考照片面部特征与体型」，脸才不漂）；想让寿星照片开口说祝福，把台词拿去对口型工具单独做；出片盘按段自动标注「图生视频 · 照片锚 / 文生视频」
- **时长 30/60 秒**；手卡导出 md 含寿星资料卡+回忆点清单+BGM 风格建议（按基调），SRT/JSON 同步；沿用「只产提示词」哲学，出片拿去即梦/可灵/剪映

## 桌面客户端（Windows）

Tauri 壳 + 冻结后端，安装包开箱即用、免登录单机运行、数据落本机。原生菜单栏（文件 / 编辑 / 视图 / 窗口 / 帮助）与前端快捷键共用一套分发；支持开**对照阅读窗**——主窗写当前章，附窗只读看别的章，主窗保存后附窗自动刷新；窗口尺寸位置自动记忆。
